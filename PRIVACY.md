# Privacy / Vie privée

**English.** Pigeons runs only on your computer. It reads, without changing them: Claude Code's local session logs
(`~/.claude/projects`), the Claude desktop app's local session files (`%APPDATA%\Claude\claude-code-sessions`, to
know whether a session is archived), and what Windows UI Automation exposes about windows on screen. It writes only in
its own folder (settings, request files, the activity registry, an error log) and, if you ask, a shortcut in the
Windows Startup folder. It sends nothing over the network and has no telemetry.

**Français.** Pigeons tourne seulement sur ton ordinateur. Il lit, sans les modifier : les journaux locaux des sessions
Claude Code (`~/.claude/projects`), les fiches locales de l'app Claude (`%APPDATA%\Claude\claude-code-sessions`, pour
savoir qu'une session est archivée), et ce que l'automatisation de Windows dit des fenêtres à l'écran. Il n'écrit que
dans son dossier (réglages, demandes, registre d'activité, journal d'erreurs) et, si tu le demandes, un raccourci dans
le dossier Démarrage de Windows. Il n'envoie rien sur le réseau et n'a aucune télémétrie.
